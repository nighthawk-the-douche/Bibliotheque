# Code

## <mark style="color:$primary;">R Class</mark>

The `R` class is auto-generated by Android and contains IDs for all resources in `res/`. Lets Java code reference XML resources by ID (e.g., `R.layout.activity_main`, `R.string.app_name`).

## <mark style="color:$primary;">Entry Point Hook</mark>

```java
@Override
protected void onCreate(Bundle savedInstanceState)
```

When Android launches this screen, this fires first. Everything starts here.

```java
setContentView(R.layout.activity_main); // sets which XML layout this Activity uses
```

## <mark style="color:$primary;">Namespace Convention</mark>

| Type                     | Format            | Direction          | Purpose                         |
| ------------------------ | ----------------- | ------------------ | ------------------------------- |
| DNS (forward)            | `mail.google.com` | Specific → General | Network routing across internet |
| Application ID (reverse) | `com.google.mail` | General → Specific | Namespace isolation on device   |

Same components, opposite order.

## <mark style="color:$primary;">CMakeLists.txt</mark>

Used to describe native C++ project files. The name assigned inside (e.g., `myapplication`) becomes the library name — matches what `native-lib.cpp` gets compiled as.

## <mark style="color:$primary;">WebViews</mark>

Components that embed and display web content directly inside an Android app.

## <mark style="color:$primary;">Activities — Code Reference</mark>

### <mark style="color:purple;">Intent (what it actually is)</mark>

Intent = data packet sent to another Activity. Just moves data. Doesn't close the source Activity.

`startActivityForResult()` = sends an Intent but keeps the source Activity alive and waiting to receive data back via `onActivityResult()`.

### <mark style="color:purple;">Starting an Activity</mark>

```java
Intent intent = new Intent(this, TargetActivity.class);
intent.putExtra("key", "test");         // attach data
startActivity(intent);                  // no result expected
startActivityForResult(intent, 1);      // result expected, code 1 identifies this request
```

### <mark style="color:purple;">Returning a Result</mark>

```java
// Target Activity sends result back
Intent resultIntent = new Intent();
resultIntent.putExtra("result_key", "result_value");
setResult(RESULT_OK, resultIntent);
finish();
```

### <mark style="color:purple;">Receiving a Result</mark>

```java
@Override
protected void onActivityResult(int requestCode, int resultCode, @Nullable Intent data) {
    super.onActivityResult(requestCode, resultCode, data);
    if (requestCode == 1 && resultCode == RESULT_OK && data != null) {
        String resultData = data.getStringExtra("result_key");
        // use resultData
    }
}
```

OS wakes up the source Activity, `onActivityResult()` catches the data, matches `requestCode` to know which request this is, then handles accordingly.

### <mark style="color:purple;">Declaring in Manifest</mark>

```xml
<application ...>
    <activity android:name=".MainActivity">
        <intent-filter>
            <action android:name="android.intent.action.MAIN" />
            <category android:name="android.intent.category.LAUNCHER" />
        </intent-filter>
    </activity>
    <!-- <activity android:name=".AnotherActivity" /> -->
</application>
```

`android.intent.action.MAIN` = entry point. First Activity launched when app starts. Critical for pentesting — defines app flow and initial attack surface.

Activities can also be launched via **ADB** (Android Debug Bridge), not just by tapping the icon or from other apps.
